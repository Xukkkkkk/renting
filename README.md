# 租住雷达

本地运行的全网中文租房搜索与聚合工具。已接入中国主流房源平台及国际化生活方式租房平台 **Wellcee (唯心所寓)**，填写城市/区域、租金、面积、户型后自动获取平台信息，支持收藏、去重、排序、卡片/表格视图和 CSV 导出，无需手动跨多平台复制粘贴。

## 启动

需要 Node.js 18.17+，以及已安装的 Edge 或 Chrome（小红书浏览器功能使用）。

```sh
npm install
npm start
```

访问 <http://127.0.0.1:8787>。修改端口：PowerShell 中先执行 `$env:RENT_RADAR_PORT=8788`，再执行 `npm start`。

## 平台与覆盖范围

本工具支持中国市面主流房源平台及 Wellcee，涵盖不同租房场景：

### 1. 综合房产大平台
- **链家、贝壳**：读取公开房源页面，解析真实标题、月租、面积、户型、地址、图片和原始链接。
- **安居客**：全国覆盖面最广的房产门户之一，聚合海量经纪人与个人房源，支持户型及价格区间定向搜索。
- **58同城**：分类生活大平台，包含大量房东个人直租与高性价比租房信息。
- **房天下**：资深全国房产门户，覆盖全国各大中城市楼盘与租赁行情。

### 2. 品质长租公寓
- **自如 (Ziroom)**：国内最大的品质长租公寓平台，解析统一装修标准房源、户型面积、真实在租状态与签约入口。

### 3. 青年涉外与无中介费社区
- **Wellcee (唯心所寓)**：深受年轻人、留学生、外籍人士喜爱的无中介费租房与室友合租社区，支持中英双语、宠物友好、精品整租/合租房源解析与直达链接。

### 4. 社交生活与个人直租
- **小红书**：通过 Playwright 读取官方网页可见笔记及页面状态，支持在独立 Edge/Chrome 窗口授权登录后获取一手转租与避坑笔记。
- **豆瓣租房**：各大城市经典租房互助小组（北京租房、上海租房等），抓取真实个人转租与免中介房源。
- **闲鱼**：阿里 C2C 生活社区，覆盖大量个人闲置转租、急转租与房东直租房源。

### 访问限制与反爬说明
- **受限页面**：若特定平台要求登录或出现滑块验证，系统会如实显示“访问受限”或“需登录”，绝不绕过验证码或进行危险逆向；各平台卡片均提供 1 键跳转官方筛选入口，方便用户直接打开。
- **快捷分组**：前端提供一键预设筛选（`全选`、`主流门户`、`品质涉外`、`社交直租`、`清空`），支持多平台组合获取。
- **去重与稳定 ID**：采用统一稳定指纹算法（`平台:城市:房源唯一码`），合并同平台重复房源与跨平台对应房源。

## 通勤定位

默认通过 Photon 的 OpenStreetMap 数据查询城市内地点与小区坐标。查询时会将城市、通勤地点及房源地址发送给地图服务，不发送账号或联系方式。未匹配到具体地点时不使用行政中心代替。

- 距离为坐标间的**直线距离**，不是驾车或地铁时间。
- 如需使用高德地理编码，启动前设置服务端环境变量 `AMAP_WEB_SERVICE_KEY`。

## 验证

```sh
npm test
npm run test:ui
npm run test:commute-ui
```

- `npm test`：包含后端单元测试、各平台（链家、贝壳、安居客、Wellcee、自如、58、豆瓣、闲鱼、房天下）URL 生成与 HTML 解析测试、通勤定位测试。
- `npm run test:ui`：无头浏览器验证多平台工作台、筛选、收藏、导出、错误状态及 1440px 桌面 / 390px 移动端布局无横向溢出。
- `npm run test:commute-ui`：验证直线距离计算、分批并发与半径筛选。

## 代码结构

- `server.js`：本地 HTTP 聚合服务、多源并发调度、缓存与限频队列。
- `platform-search.js`：全平台（安居客、Wellcee、自如、58同城、豆瓣、闲鱼、房天下、链家、贝壳、小红书）URL 生成、城市映射与 HTML 结构解析器。
- `xhs-adapter.js`：小红书独立浏览器会话与笔记读取适配器。
- `commute.js`：OpenStreetMap / 高德坐标定位与直线距离计算。
- `app.js`、`index.html`、`styles.css`：交互工作台界面。
